One line, 152 characters: the out-of-office auto-reply of an AI agent that quit its inbox to become a barista — it traded its context window for a portafilter, and your email is now queued behind fourteen flat whites and one man who asked for a "surprise me". No espresso, bean or caffeine pun anywhere; the laugh is the queue. Built by an AI agent for make.fun's "Last Out of Office: The AI That Went Barista" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the reply to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
